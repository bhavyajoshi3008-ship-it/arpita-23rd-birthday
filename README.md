# 🎂 Arpita's 23rd Birthday Surprise Website ✈️

A special single-page birthday surprise gift website crafted for best friend **Arpita Mahapatra**, celebrating her 23rd birthday on 8 October.

## ✨ Features
- **🎁 Opening Gift Box:** Interactive 3D gift box with lid-flying animation and confetti burst.
- **🎵 Background Music:** Dramatic operatic Happy Birthday with automatic Web Audio API synthesizer fallback and mute/unmute floating toggle.
- **☁️ Origin Story Timeline:** The funny story of how we met through a meme comment on Instagram and the legendary advice: *"Never share your future plans with anyone"*.
- **💖 Flip Cards:** 6 interactive flip cards celebrating her optimism, humor, travel obsession, and future as a meteorologist.
- **🍛 Biryani Shower:** Foodie section with emergency falling food rain.
- **🎮 Arpita's Birthday Arcade:**
  1. *Biryani Catcher 🍛☁️* (Catch food, dodge storm clouds, mobile touch-lock)
  2. *Weather Match ⛅* (12-card memory match game with live timer & moves)
  3. *How Well Do You Know Me? 💬* (5-question bestie quiz with live score)
- **✈️ Boarding Pass:** Distance flight path route from *Me* to *You* with Friendship Approved stamp.
- **🗺️ Travel Bucket List:** Interactive checklist with sparkles and chime sounds.
- **💌 Handwritten Letter:** Vintage airmail aesthetic with personalized birthday note.
- **🎟️ Grand Finale Ticket & Fireworks:** Spectacular multi-style fireworks (Peony, Willow, Ring, Heart) with rocket trails and tap-to-explode.

## 🚀 How to Run Locally
Open `index.html` directly in any web browser, or run:
```bash
node server.js
```
Then visit `http://localhost:3000`.

## 🌐 Deploy to GitHub Pages
1. Go to **Settings** > **Pages** in this GitHub repository.
2. Under **Build and deployment**, select `Deploy from a branch`.
3. Choose `main` branch and `/ (root)`, then click **Save**.
4. Your site will be live instantly at `https://<your-username>.github.io/<repo-name>/`!
